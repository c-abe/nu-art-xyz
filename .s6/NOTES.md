## 触る前に知っておくこと

- **画像を作り直したら `index.html` の `IMG_VER` を1つ増やす。**
  ファイル名が同じなのでブラウザが古い画像を使い続ける
- **GitHub Desktop に常に出る「2 changed files」はコミットしない。**
  ファイル名の文字コードが違うだけの画像2点。入れると画像が二重になる
- 作業のあとは必ず `node tools/test_detail.mjs`（69項目）
- そのテストは jsdom を使う。無いと動かない → `cd /tmp/jt && npm i jsdom`
- Push はこの環境からできない。GitHub Desktop から行う

## 試して、やめたこと

同じ道を二度通らないための記録。

- **敷き詰めて並べる TOP** … インスタと同じ見た目になるのでやめた
- **部屋のモックを TOP に並べる** … 背景がうるさく、作品が負けた
- **漂わせる／カーソルの軌跡** … 見比べた結果、球を選んだ（試作は `tools/motion.html`）
- **Mockup.psd（立てかけ）** … 枠が下地に斜めに焼き込まれていて、
  印刷面を 1:√2 に直すと必ずずれる
- **シリーズを選ぶ帯（Collection＋ボタン＋点数）** … 球から直接入れるので要らない
- **判型を無視した額** … A4 も B3 も部屋の中で同じ大きさに見え、値段の差が伝わらなかった
- **既製モックの1枚（women01_cut1）** … 額の大きさを変えられないので外した
- **額のないポスターを全判型に使う** … 下地に光の漏れが焼き込まれていて、
  面を小さくすると跡が白い四角で残る。B3 の作品にだけ使う
- **比率の合わない額** … 作品は全40点が 1:√2。合わない額は作品の端を切るので外した
